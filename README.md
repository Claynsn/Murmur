# Murmur

An experimental framework exploring agent swarms and emergent intelligence, 
with optional on-chain primitives for agent coordination and value exchange.

## Status

Early exploration (April 2026). Architecture in design.

## Vision

Most agent frameworks today focus on single-agent workflows. 
Murmur explores what happens when many small agents interact under 
simple rules: coordination, negotiation, emergent strategies.

Optional on-chain layer for:
- Agent-to-agent micropayments
- Verifiable agent identity
- Persistent reputation

## Roadmap

- [ ] Core agent loop (single agent, Claude backbone)
- [ ] Multi-agent message bus
- [ ] Minimal simulation environment
- [ ] On-chain settlement experiment (Base or Solana)
